YEH FOLDER KYA HAI?
--------------------
Yeh "public" folder tumhari website ka media storage hai.
Jو bhi file yahan hogi, woh seedha website pe available hogi.

Example: public/images/projects/my-project.jpg
Website pe URL hoga: haditech.com/images/projects/my-project.jpg


FOLDER STRUCTURE — KYA KAHAN JATA HAI
---------------------------------------

public/
│
├── images/
│   ├── projects/        ← Project screenshots yahan
│   │   ├── crm-1.jpg
│   │   ├── crm-2.jpg
│   │   └── bot-1.jpg
│   │
│   ├── testimonials/    ← Client avatars/photos yahan
│   │   └── client-john.jpg
│   │
│   ├── blog/            ← Blog post cover images yahan
│   │   └── nextjs-guide.jpg
│   │
│   └── team/            ← Tumhari apni photo yahan
│       └── hadi-avatar.jpg
│
├── videos/              ← SIRF CHHOTI GIF animations
│   └── hero-loop.gif    (Real videos YouTube pe hoti hain)
│
├── icons/               ← Custom SVG icons
│   └── logo.svg
│
├── fonts/               ← Custom fonts (agar locally serve karne hon)
│
├── favicon.ico          ← Website tab icon
├── og-image.png         ← Social share image (1200x630px)
└── robots.txt           ← SEO (auto-generated by Next.js)


RULES — YEH GHALTIYAN MAT KARO
---------------------------------
❌ Videos (mp4, webm) kabhi mat rakho — YouTube pe upload karo
❌ 1MB se bari images mat rakho — pehle compress karo
❌ node_modules ya .next folder ko touch mat karo
✅ Images hamesha compress karo: squoosh.app (free)
✅ Format: JPG for photos, PNG for screenshots, SVG for icons
✅ Size: Project screenshots 1200x630px, Avatars 200x200px


DATA.TS ME KAISE USE KARO
----------------------------
Jab image public/images/projects/my-app.jpg mein ho:

data.ts mein likho:
  thumbnailSrc: "/images/projects/my-app.jpg"
  screenshots: ["/images/projects/my-app-1.jpg", "/images/projects/my-app-2.jpg"]

Bas "/" se shuru karo — "public/" nahi likhna!


DEPLOY KARNA
--------------
1. Image public folder mein rakho
2. data.ts mein path update karo
3. git add .
4. git commit -m "add project images"
5. git push
6. Vercel 90 seconds mein live kar dega ✅
